📖 Definition
-------------

Object-Oriented Programming (OOP) is a programming paradigm that organizes
programs using "Objects" instead of only functions.

An Object contains both:

    1. Data (Variables)
    2. Functions (Member Functions)

The main purpose of OOP is to make programs more organized, reusable,
secure, and easy to maintain.

--------------------------------------------------------------------------------

⭐ Why was OOP introduced?
-------------------------

Before OOP, programmers used Procedural Programming.

Example:

main()
{
    addStudent();
    deleteStudent();
    updateStudent();
    searchStudent();
    printStudent();

    addTeacher();
    deleteTeacher();
    updateTeacher();
}

As the program grows, thousands of functions are created.

Problems:

❌ Difficult to understand
❌ Difficult to debug
❌ Difficult to maintain
❌ No proper security
❌ Code duplication

To solve these problems, OOP was introduced.

--------------------------------------------------------------------------------

⭐ What is a Programming Paradigm?
---------------------------------

Programming Paradigm means

"A style or method of writing programs."

Examples

1. Procedural Programming
2. Object-Oriented Programming
3. Functional Programming
4. Logical Programming

================================================================================
                                LESSON - 2
                             CLASS AND OBJECT
================================================================================

📖 Definition
-------------

A Class is a user-defined data type that acts as a blueprint or template
for creating objects.

An Object is a real instance (copy) of a class that occupies memory.

Simply,

Class  → Blueprint

Object → Real Thing

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Class is a template.

✔ Object is an instance of a class.

✔ A class does not occupy memory until an object is created.

✔ Memory is allocated only when an object is created.

✔ One class can create many objects.

--------------------------------------------------------------------------------

❓ Why do we need Classes?
-------------------------

Suppose we want to store information of 100 students.

Without Class

name1
roll1
marks1

name2
roll2
marks2

name3
roll3
marks3

...

This becomes very difficult to manage.

Using Class

class Student
{
    name
    roll
    marks
};

Now we can create

Student s1;
Student s2;
Student s3;

The code becomes clean and reusable.

--------------------------------------------------------------------------------

🧠 Real-Life Analogy
-------------------

Suppose a company manufactures cars.

The company first prepares a DESIGN.

That design is called

CLASS

Every car manufactured using that design is called

OBJECT

Example

                Car Design
                    │
         -----------------------
         │         │          │
      Car 1      Car 2      Car 3

Class is one.

Objects can be many.

--------------------------------------------------------------------------------

📊 Diagram

              +----------------+

                Name

                Display()

              +----------------+

                     │

         ----------------------------

         │             │            │

      Student1     Student2     Student3

        Object       Object       Object

================================================================================
                               LESSON - 3
                           ACCESS SPECIFIERS
================================================================================

📖 Definition
-------------

Access Specifiers are keywords that control the accessibility (visibility)
of data members and member functions inside a class.

They decide who can access the members of a class.

There are three access specifiers in C++:

1. Public
2. Private
3. Protected

--------------------------------------------------------------------------------

⭐ Why do we need Access Specifiers?
-----------------------------------

Suppose you create a Bank Account class.

Everyone should NOT be allowed to change the account balance directly.

Wrong

Account.balance = 10000000;

Instead,

Only specific functions should modify the balance.

Access Specifiers provide SECURITY.

--------------------------------------------------------------------------------

⭐ Types of Access Specifiers
----------------------------

1. Public

Members can be accessed from anywhere.

Example

class Student
{
public:
    string name;
};

Student s;
s.name = "Mayank";

------------------------------------------------

2. Private

Members can be accessed ONLY inside the same class.

Example

class Student
{
private:
    int marks;
};

Student s;

// s.marks = 90; ❌ Error

------------------------------------------------

3. Protected

Members can be accessed

✔ Inside the class

✔ Inside derived (child) classes

❌ Not from outside the class

--------------------------------------------------------------------------------

📊 Diagram

                     CLASS

            +----------------------+

            PUBLIC

            Accessible Everywhere

            ----------------------

            PRIVATE

            Accessible Only
            Inside Same Class

            ----------------------

            PROTECTED

            Accessible in
            Child Classes

            +----------------------+

--------------------------------------------------------------------------------

📝 Syntax
---------

class Student
{

public:

    string name;

private:

    int marks;

protected:

    int roll;

};

--------------------------------------------------------------------------------

⚙ Working
----------

Object Created

↓

Public members

↓

Accessible using Dot Operator

----------------------------------

Private members

↓

Cannot be accessed directly

----------------------------------

Protected members

↓

Used mainly in Inheritance

--------------------------------------------------------------------------------

💻 Example 1 (Public)

#include<iostream>
using namespace std;

{
public:

};

{

================================================================================
                               LESSON - 4
                           GETTER & SETTER
================================================================================

📖 Definition
-------------

Getter and Setter are member functions used to access and modify
private data members of a class.

They provide controlled access to private variables.

Getter → Used to Read (Get) Data

Setter → Used to Modify (Set) Data

--------------------------------------------------------------------------------

⭐ Why do we need Getter & Setter?
---------------------------------

Private variables cannot be accessed directly from outside the class.

Example

class Student
{
private:
    int marks;
};

int main()
{
    Student s;

    s.marks = 95;     // ❌ Error
}

Since marks is private, we need special functions.

Setter → Stores value.

Getter → Returns value.

--------------------------------------------------------------------------------

🧠 Real-Life Analogy
-------------------

Imagine an ATM Machine.

You cannot directly open the ATM and change your account balance.

Instead,

You interact using

✔ Deposit

✔ Withdraw

✔ Check Balance

Similarly,

Private Variables

↓

Cannot be accessed directly.

↓

Getter & Setter act as the authorized gateway.

--------------------------------------------------------------------------------

📊 Diagram

                 USER

                   │

          setMarks(95)

                   │

                   ▼

            +----------------+

            |    SETTER      |

            +----------------+

                   │

                   ▼

         Private Variable (marks)

                   ▲

                   │

            +----------------+

            |    GETTER      |

            +----------------+

                   │

           getMarks()

                   │

                   ▼

                 USER

--------------------------------------------------------------------------------

⭐ Advantages
------------

✔ Data Security

✔ Data Hiding

✔ Controlled Access

✔ Easy Validation

✔ Better Encapsulation

✔ Easy Maintenance

--------------------------------------------------------------------------------

📝 Syntax
---------

class Student
{
private:

    int marks;

public:

    void setMarks(int m)
    {
        marks = m;
    }

    int getMarks()
    {
        return marks;
    }
};

--------------------------------------------------------------------------------

⚙ Working
----------

Step 1

Object is created.

↓

Step 2

Setter receives value.

↓

Step 3

Setter stores value in private variable.

↓

Step 4

Getter returns that value whenever required.

--------------------------------------------------------------------------------

💻 Example 1 (Basic Getter & Setter)

#include<iostream>
using namespace std;

class Student
{
private:

    int marks;

public:

    void setMarks(int m)
    {
        marks = m;
    }

    int getMarks()
    {
        return marks;
    }
};

int main()
{
    Student s;

    s.setMarks(95);

    cout<<"Marks : "<<s.getMarks();

    return 0;
}

--------------------------------------------------------------------------------

📤 Output

📖 Definition
-------------

A Constructor is a special member function of a class that is
automatically called whenever an object of that class is created.

Its main purpose is to initialize the data members of an object.

Unlike normal functions, constructors are called automatically and
do not require an explicit function call.

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Constructor name must be the same as the class name.

✔ Constructors have NO return type.

✔ Constructors are called automatically.

✔ Constructors initialize object data.

✔ Constructors can be overloaded.

✔ Every class can have multiple constructors.

✔ If no constructor is written, the compiler provides a Default Constructor.

--------------------------------------------------------------------------------

❓ Why do we need Constructors?
-------------------------------

Without Constructor

class Student
{
public:

    string name;
    int age;
};

int main()
{
    Student s;

    s.name = "Mayank";
    s.age = 16;
}

Every object must be initialized manually.

----------------------------------------------

With Constructor

Student(string n,int a)
{
    name = n;
    age = a;
}

Initialization becomes automatic.

--------------------------------------------------------------------------------

🧠 Real-Life Analogy
--------------------

Suppose you buy a new mobile phone.

Before using it,

Manufacturer already provides

✔ Battery

✔ Screen

✔ Camera

✔ Software

Everything is initialized.

Similarly,

A Constructor prepares an object before we start using it.

📖 Definition
-------------

A class can have multiple constructors with different parameter lists.
This feature is known as Constructor Overloading.

A Copy Constructor is a special constructor that creates a new object
by copying the values of an existing object.

--------------------------------------------------------------------------------

⭐ Constructor Overloading
--------------------------

Constructor Overloading means creating more than one constructor
inside the same class with different parameters.

The compiler decides which constructor to call based on
the number and type of arguments.

--------------------------------------------------------------------------------

🧠 Real-Life Analogy
--------------------

Think of a Mobile Phone.

You can buy it

✔ Without Accessories

✔ With Charger

✔ With Charger + Earphones

Same mobile

Different ways to initialize.

This is Constructor Overloading.

--------------------------------------------------------------------------------

📊 Diagram

                Student Class

                     │

        --------------------------------

        Student()

        Student(string)

        Student(string,int)

        Student(string,int,double)

        --------------------------------

                 Different Constructors

--------------------------------------------------------------------------------

📝 Syntax

class Student
{
public:

    Student();

    Student(string);

    Student(string,int);

};

--------------------------------------------------------------------------------

💻 Example 1 : Constructor Overloading

#include<iostream>
using namespace std;

class Student
{
public:

    Student()
    {
        cout<<"Default Constructor"<<endl;
    }

    Student(string name)
    {
        cout<<"Name : "<<name<<endl;
    }

    Student(string name,int age)
    {
        cout<<"Name : "<<name<<endl;
        cout<<"Age  : "<<age<<endl;
    }
};

int main()
{
    Student s1;

    Student s2("Mayank");

    Student s3("Mayank",16);

    return 0;
}

--------------------------------------------------------------------------------

⭐ Copy Constructor
------------------

A Copy Constructor creates a new object by copying another object
of the same class.

Syntax

ClassName(ClassName &obj)

{

}

--------------------------------------------------------------------------------

🧠 Why do we need Copy Constructor?
-----------------------------------

Suppose we already have an object.

Student s1("Mayank",16);

Now we want another object having exactly the same values.

Instead of assigning each variable again,

We simply write

Student s2(s1);

Everything gets copied automatically.

💻 Example 3 : User Defined Copy Constructor

#include<iostream>
using namespace std;

class Student
{
public:

    string name;
    int age;

    Student(string n,int a)
    {
        name = n;
        age = a;
    }

    Student(const Student &obj)
    {
        name = obj.name;
        age = obj.age;
    }

    void display()
    {
        cout<<"Name : "<<name<<endl;
        cout<<"Age  : "<<age<<endl;
    }
};

int main()
{
    Student s1("Mayank",16);

    Student s2(s1);

    s2.display();

    return 0;
}

--------------------------------------------------------------------------------

📤 Output

Name : Mayank

Age  : 16

--------------------------------------------------------------------------------

⭐ Why use const Student &obj ?

✔ No unnecessary copy is created.

✔ Faster.

✔ Prevents accidental modification.

Professional C++ programmers generally write

Student(const Student &obj)

instead of

Student(Student &obj)

--------------------------------------------------------------------------------

⭐ Difference Between Parameterized Constructor
and Copy Constructor

Parameterized Constructor

✔ Receives Normal Values

Student("Mayank",16);

--------------------------------------------

Copy Constructor

✔ Receives Object

Student(s1);

--------------------------------------------------------------------------------

⭐ Compiler Generated Copy Constructor

If you do not write your own Copy Constructor,

the compiler automatically creates one.

It performs

SHALLOW COPY

which is sufficient for simple variables.

For dynamic memory, you should write your own
copy constructor to perform a DEEP COPY.

(We'll study this later.)

--------------------------------------------------------------------------------

-----------------

This creates another copy while passing the argument.

Correct

------------------------------------------------

❌ Forgetting '&'

Student(Student obj)

Wrong

Correct

Student(const Student &obj)

------------------------------------------------

❌ Thinking

Actually,

During initialization,

📖 Definition
-------------

A Static Data Member is a class member that is shared by all the objects
of that class.

Only ONE copy of the static variable exists in memory,
regardless of how many objects are created.

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Shared among all objects.

✔ Memory allocated only once.

✔ Declared using static keyword.

✔ Defined outside the class.

✔ Can be accessed using

    ClassName::VariableName

--------------------------------------------------------------------------------

❓ Why Static Member?

Normally

Student s1;

Student s2;

Student s3;

Each object has its own copy.

But suppose we want to count

Total Students

The count should be common for all objects.

Hence,

Static Variable is used.

--------------------------------------------------------------------------------

🧠 Real Life Example
-------------------

Suppose

School Name = DPS

Every student studies in the same school.

There is no need to store

"DPS"

inside every object.

One common variable is enough.

--------------------------------------------------------------------------------

📊 Diagram

            Student Class

           -------------------

           Name

           Roll

           Age

           -------------------

           static SchoolName

           static Count

           -------------------

              Shared By

      s1      s2      s3

--------------------------------------------------------------------------------

📝 Syntax

class Student
{
public:

    static int count;

};

--------------------------------------------------------------------------------

💻 Example 1

################################################################################
                         PART - 1 : THIS POINTER
################################################################################

📖 Definition
-------------

The "this" pointer is a special pointer automatically created for every
non-static member function.

It points to the current object that calls the member function.

In simple words,

this = Address of Current Object

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Automatically created by compiler.

✔ Available only inside member functions.

✔ Points to current object.

✔ Used to remove ambiguity between local and class variables.

✔ Cannot be used inside static member functions.

--------------------------------------------------------------------------------

❓ Why do we need this Pointer?
-------------------------------

Consider

class Student
{
public:

    string name;

    Student(string name)
    {
        name = name;
    }
};

Both variables have the same name.

Compiler gets confused.

Here,

this pointer solves the problem.

--------------------------------------------------------------------------------

🧠 Real Life Analogy
-------------------

Suppose a teacher says

"Bring MY notebook."

"My" refers to the teacher himself.

Similarly,

this refers to the current object.

--------------------------------------------------------------------------------

📊 Diagram

          Student s1

        Name = Mayank

              │

              ▼

        Student()

              │

              ▼

this ---------> s1

--------------------------------------------------------------------------------

📝 Syntax

this->variable = variable;

--------------------------------------------------------------------------------

💻 Example 1

#include<iostream>
using namespace std;

class Student
{
public:

    string name;
    int age;

    Student(string name,int age)
    {
        this->name = name;
        this->age = age;
    }

    void display()
    {
        cout<<"Name : "<<name<<endl;
        cout<<"Age  : "<<age;
    }
};

int main()
{
    Student s("Mayank",16);

    s.display();

    return 0;
}

--------------------------------------------------------------------------------

📤 Output

Name : Mayank

Age  : 16

--------------------------------------------------------------------------------

💻 Example 2

#include<iostream>
using namespace std;

class Demo
{
public:

    {
        this->x = x;
    }

    {
        cout<<x;
    }
};

int main()
{
    Demo d;

    d.setValue(100);

    d.show();

    return 0;
}

--------------------------------------------------------------------------------

📤 Output

100

--------------------------------------------------------------------------------

⭐ Uses of this Pointer

✔ Resolves name conflict.

✔ Returns current object.

✔ Supports method chaining.

✔ Used in constructors.

✔ Used in operator overloading.

--------------------------------------------------------------------------------

⚠ Common Mistakes

Both refer to local variable.

------------------------------------------------

Correct

------------------------------------------------

❌ Using this inside static function

Wrong

Static functions have no object.

📖 Definition
-------------

A Destructor is a special member function that is automatically called
when an object is destroyed.

It is mainly used to release resources such as memory, files,
or database connections.

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Same name as class.

✔ Starts with ~

✔ No return type.

✔ No parameters.

✔ Automatically called.

✔ Only one destructor per class.

✔ Cannot be overloaded.

--------------------------------------------------------------------------------

❓ Why Destructor?
------------------

Suppose an object allocates memory dynamically.

After finishing the work,

memory should be released.

Destructor performs this cleanup automatically.

--------------------------------------------------------------------------------

🧠 Real Life Analogy
-------------------

Constructor

↓

Entering a Classroom.

You arrange everything.

----------------------------------------

Destructor

↓

Leaving the Classroom.

You switch off lights,

close windows,

clean everything.

--------------------------------------------------------------------------------

📊 Diagram

Object Created

↓

Constructor Called

↓

Program Executes

↓

📖 Definition
-------------

Inheritance is an Object-Oriented Programming (OOP) feature in which one
class acquires the properties (data members) and behaviors (member functions)
of another class.

The existing class is called the Base Class (Parent Class), and the new
class is called the Derived Class (Child Class).

Inheritance promotes Code Reusability.

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Reuse existing code.

✔ Avoid code duplication.

✔ Child class inherits properties of parent class.

✔ Supports Hierarchical Relationships.

✔ Makes programs easier to maintain.

✔ One of the four pillars of OOP.

📖 Definition
-------------

A Friend Function is a function that is NOT a member of a class,
but it is allowed to access the private and protected members
of that class.

Normally, only member functions can access private data.
A Friend Function is an exception to this rule.

--------------------------------------------------------------------------------

⭐ Key Points
------------

✔ Not a member of the class.

✔ Declared using the friend keyword.

✔ Can access private members.

✔ Can access protected members.

✔ Called like a normal function.

✔ Has no this pointer.

--------------------------------------------------------------------------------

❓ Why do we need Friend Function?
---------------------------------

Suppose two classes need to share their private data.

Without Friend Function,

outside functions cannot access private members.

Friend Function solves this problem.

--------------------------------------------------------------------------------

🧠 Real-Life Analogy
-------------------

Imagine a Bank Locker.

Normally,

Only the Owner can open it.

But the owner gives special permission
to the Bank Manager.

The manager can also access the locker.

Similarly,

Friend Function gets special permission
to access private members.

--------------------------------------------------------------------------------

               Student Class

        --------------------------

        Private Data

        Name

                    │

                    ▼

      Can Access Private Members

---------

{
